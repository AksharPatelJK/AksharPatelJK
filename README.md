## `$ whoami`

I'm **Akshar Patel**, a Software Developer based in **Bengaluru, India**, working primarily on **Manufacturing Execution Systems (MES)** and enterprise software applications.

My work involves building and maintaining applications that connect manufacturing processes with software — from equipment and work orders to WIP tracking, downtime, quality and production dashboards.

I work mainly with **C#, ASP.NET Core, Angular, React, TypeScript and SQL Server**, while also working with MES platforms and manufacturing technologies such as **Camstar / Siemens Opcenter and ALite**.

I enjoy understanding how systems work internally, debugging real-world problems, and continuously improving my development skills.
